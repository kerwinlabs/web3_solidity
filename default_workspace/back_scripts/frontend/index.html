Deposit Mode / 存款方式
一步存款：调用 transferAndCall， Token 转入与 TokenBank 记账在同一笔交易完成，无需 approve；仅适用于 CalledToken。
Permit 签名存款：先用钱包对 Permit(owner, spender=TokenBank, value, nonce, deadline) 做 EIP-712 离线签名（不消耗 gas、不发交易），再提交一笔 permitDeposit 完成授权 + 转账 + 记账。签名有效期 30 分钟，每次存款使用当前 nonce 重新签名； 仅支持 EIP-2612 的代币（如 MyPermitToken）。
Permit2 签名存款：首次使用先在 Step 1 对 Uniswap Permit2 （—）授权一次，之后每笔存款只需对 PermitTransferFrom(permitted, spender=TokenBank, nonce, deadline) 做 EIP-712 离线签名（不消耗 gas），再提交一笔 depositWithPermit2 完成转账与记账。 适用于不支持 EIP-2612 的普通 ERC-20。
